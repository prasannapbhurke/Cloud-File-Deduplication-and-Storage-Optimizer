HOW TO RUN THE PROJECT (QUICK START)
========================================================================

METHOD 1: ONE-CLICK LAUNCH (WINDOWS)
  Double-click 'run_app.bat' in this folder.
  It will install requirements and open the dashboard in your browser at:
  http://127.0.0.1:5000

METHOD 2: TERMINAL / COMMAND PROMPT
  1. Open terminal in this folder.
  2. Install dependencies:
       pip install -r requirements.txt
  3. Start the application:
       python app.py
  4. Open your browser and visit:
       http://127.0.0.1:5000

METHOD 3: RUN THE AUTOMATED TEST SUITE
  To verify deduplication, run:
       python test_dedup.py
  This runs all 5 automated tests (100% duplicate detection, partial modification,
  byte-for-byte reconstruction, and storage analytics).

METHOD 4: COMMAND LINE INTERFACE (CLI)
  To test using CLI:
       python cli.py
